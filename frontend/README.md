# ArchiteX Frontend

Modern React + Vite frontend for ArchiteX — AI Architecture Intelligence, Dependency Graph Visualization, and Automated Codebase Remediation.

## Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
The app will be available at [http://localhost:3000](http://localhost:3000).

### 3. Build for Production
```bash
npm run build
```

## Tech Stack
* **Framework:** React 19 + Vite 6
* **Canvas / Graphs:** React Flow (`reactflow`)
* **Styling:** Pure Vanilla CSS with Obsidian Cybernetic theme
* **Icons:** Lucide React (`lucide-react`)
* **HTTP Client:** Axios
